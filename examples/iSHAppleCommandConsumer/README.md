# 独立命令消费者

这个示例只依赖公开的 `iSHAppleSwift` 模块。它先启动进程级 runtime，再通过
结构化会话运行 guest 命令，并分别接收 stdout 与 stderr。

输出通道使用固定字节容量并把消费速度反压到 guest。调用方必须像示例一样，
让 `output` 的遍历和 `result()` 并发执行；如果只等待结果而不消费输出，一个
持续输出的命令会在缓冲区满后按设计暂停。

取消遍历输出、写入 stdin 或等待结果的 Swift `Task`，都会把取消传给原生命令
会话。显式调用 `cancel()` 也会关闭本地输出序列，并以取消错误结束遍历。
